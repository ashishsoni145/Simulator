Build a Futuristic Interactive 3D Science Learning Platform

Build a premium educational web application called Science 3D — an interactive 3D learning platform for Class 11 and Class 12 Physics and Chemistry, focused on learning concepts through simulations, experiments, visualizations, and interactive 3D artifacts rather than static notes.

The final product should feel like a combination of:

- A futuristic virtual science laboratory
- PhET-style interactive simulations
- A premium modern education platform
- A 3D scientific visualization tool
- A game-like exploration experience
- An AI-powered learning assistant

This must look like a real startup-quality product, not a generic educational dashboard.

---

1. TECH STACK

Use:

- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- React Three Fiber
- @react-three/drei
- OGL
- Lucide React icons
- Framer Motion where appropriate

Use a clean component architecture.

The application must be responsive and work well on:

- Desktop
- Laptop
- Tablet
- Mobile

Prioritize performance because the application will eventually contain many WebGL/3D simulations.

4. GALAXY BACKGROUND

Integrate the React Bits Galaxy component as a major part of the visual identity.

Use the JavaScript + CSS version of the Galaxy component with the "ogl" dependency.

Install:

npm install ogl

Create:

src/components/Galaxy/Galaxy.jsx
src/components/Galaxy/Galaxy.css

Use the supplied Galaxy component source exactly as the implementation basis.

Import it where needed:

import Galaxy from "./components/Galaxy/Galaxy";

Example:

<div
  style={{
    width: "100%",
    height: "600px",
    position: "relative"
  }}
>
  <Galaxy />
</div>

For the primary landing page use a configuration similar to:

<Galaxy
  mouseRepulsion={true}
  mouseInteraction={true}
  density={1.5}
  glowIntensity={0.5}
  saturation={0.8}
  hueShift={220}
  starSpeed={0.4}
  twinkleIntensity={0.35}
  rotationSpeed={0.08}
  transparent={true}
/>

The Galaxy must remain a background layer, not interfere with content readability.

Use it particularly on:

- Landing page hero
- Authentication screens
- Empty states
- Major section transitions
- Possibly the simulation loading screen

Do not put a heavy Galaxy WebGL canvas behind every dashboard card because that could hurt performance.

Use appropriate z-index layering:

Galaxy
↓
dark gradient overlay
↓
content

Add subtle radial gradients above the Galaxy to ensure text remains readable.

21. PERFORMANCE

This is critical.

Optimize WebGL rendering.

Requirements:

- Lazy-load simulations
- Don't initialize WebGL until required
- Dispose Three.js resources correctly
- Dispose geometries
- Dispose materials
- Dispose textures
- Stop animation loops when simulation is not visible
- Avoid unnecessary React re-renders
- Use requestAnimationFrame correctly
- Use dynamic imports for heavy simulations
- Keep Galaxy background limited to appropriate pages
- Provide reduced-motion support

Add a loading state:

Preparing your laboratory...

with a subtle scientific animation.

  id: string;

  classLevel: 11 | 12;
  chapter: string;
  description: string;
  difficulty: "beginner" | "intermediate" | "advanced";
