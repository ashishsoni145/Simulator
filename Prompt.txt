You are taking over an existing React/TypeScript project called Science 3D.

The project is an interactive 3D Physics and Chemistry learning platform for Class 11 and Class 12.

GitHub/Copilot has already created the initial implementation. Your job is to inspect the entire existing codebase first, understand what has actually been implemented, then improve and complete it without unnecessarily rewriting working code.

---

1. FIRST: AUDIT THE PROJECT

Before making changes:

1. Inspect the complete repository structure.
2. Inspect "package.json".
3. Identify the framework and build system.
4. Inspect all existing pages/components.
5. Identify existing 3D/simulation components.
6. Identify existing routing.
7. Identify existing styling/design system.
8. Identify existing state management.
9. Identify existing data models.
10. Identify broken, incomplete, placeholder, duplicated, or dead functionality.
11. Run the application.
12. Run the existing build.
13. Fix any compilation/runtime errors you discover.

Do NOT immediately replace the existing architecture.

Reuse good existing code.

2. PRODUCT GOAL

The application should become a premium platform called:

Science 3D

16. PERFORMANCE

This application will eventually contain hundreds of 3D simulations.

Therefore:

- Lazy-load simulations
- Dynamically import heavy components
- Do not initialize every WebGL canvas on page load
- Dispose Three.js geometries/materials/textures
- Stop animation loops when components unmount
- Avoid unnecessary React state updates per frame
- Use refs for high-frequency animation state
- Use requestAnimationFrame appropriately
- Avoid expensive DOM updates every frame
- Optimize mobile rendering
- Respect "prefers-reduced-motion"
