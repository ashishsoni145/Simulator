Science 3D — Starter scaffold

This repository is a starter scaffold for Science 3D, a futuristic interactive 3D science learning platform.

Getting started:

1. Install dependencies: npm install
2. Run development server: npm run dev

Notes:
- The Galaxy background component uses ogl. It is placed as an absolutely positioned canvas behind content.
- Simulations are lazy-loadable and located under src/simulations/. The Projectile Motion simulation is provided as an example.
- This scaffold focuses on visual identity, responsive layout, and a starting simulation architecture. Continue building simulations and UI features per the full spec.
